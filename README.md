# ppt-wanmeidashi

这是一份给 AI 代理使用的 PPT 视觉设计技能，正文在 `SKILL.md`。

做或美化演示文稿时，先按对比、重复、对齐、亲密性，以及字体与配色要点检查版式，再用适用于幻灯片的去套模板底线过一遍，然后让模型写提示词并出图，而不是手写超长提示词。

## 使用

把 `SKILL.md` 放到代理的技能目录中即可。

## 说明

- 设计原则用自己的话转述自 Robin Williams《写给大家看的设计书》中公开讲授的规则。本仓库不含原书正文或文件。
- 去套模板味的底线改写自 [Hallmark](https://github.com/nutlope/hallmark)（MIT）和 [anthropics/skills](https://github.com/anthropics/skills) 里适用于幻灯片的部分（Apache 2.0），不是整套网页流程或官方技能目录的原样搬运。
- 请勿用本技能抄录或分发受版权保护的书籍内容。
